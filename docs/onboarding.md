# 用户配置与逐步接入流程

更新时间：2026-10-12。主职责：用户第一次怎样开始，之后怎样增加、改变或停止来源。

用户可以在 dot 中开始，由 dot 按引导流程调用真实命令；也可以运行 python3 personal-agent --workspace ~/PersonalContext setup 使用问答引导。只询问会改变采集、处理或提供范围的选择，技术字段由工具维护。参见[命令与协议](commands.md)和[引导提示词](../prompts/setup-guide.md)。

## 首次配置

1. 用户在 dot 中说明希望建立个人 Agent，并提供 Harness 入口；按需完成电脑连接。dot 带用户选择工作区，填写称呼、时区与当前希望 Agent 帮助的事情。用户可以先手工填写背景和目标。
2. 分别选择 Codex、ChatGPT、微信、健康、消费、日记或其他文件。初次未选择的来源保持关闭。
3. 对每个来源决定读取范围、是否参与个人理解、哪些内容允许 dot 使用。提供时间范围、会话或文件选择、略过列表；既可只归档，也可参与消化。
4. 根据已选来源显示实际步骤。已有本地记录的来源直接读取；需要账号导出的来源说明如何投放；需要登录或设备迁移的来源等待用户完成相应步骤。
5. 处理用户选择的首批材料，生成脱敏阅读副本。展示实际收到的范围和脱敏类型，不在结果中显示秘密值。
6. Agent 阅读首批资料并维护 Wiki。用户查看已有事实、目标、约束和重要待确认项，直接纠正；修正落到对应主落点。
7. 向 dot 提供允许读取的真实工作区或脱敏包，生成含路径、读取顺序和回写职责的初始化说明，开始日常上下文使用。
8. 用户选择是否开启持续整理，以及频率、时区、通知条件和同步方式。读取保存的任务安排与实际结果。

没有启用的来源不阻止已选材料进入个人库。需要登录的步骤只影响对应来源；已有材料可以继续形成理解。第一轮形成实际可用的 Wiki 并被 dot 读取后，用户即可开始日常交流，后续逐个补充资料。

## 来源选择应分开表达

| 选择 | 用户决定的内容 |
| --- | --- |
| 收取什么 | 时间、会话、文件、账户和忽略范围 |
| 理解什么 | 参与个人 Wiki，或只保留可回查归档 |
| dot 使用什么 | Wiki、选定脱敏来源，或暂不提供该来源 |
| 继续获取什么 | 手动补充，或保存周期任务 |

模型阅读资料会将被读取的内容交给相应模型服务。界面据此区分“原件只保存在本地”与“阅读副本会被 Agent 使用”。只在本地保存原件不等于使用云端模型时数据从未离开本机。

## 各来源的操作说明

| 来源 | 首版操作 | 后续补充 |
| --- | --- | --- |
| Codex | 选择本机日志位置、主会话范围和历史时间 | 增量读取新会话与更新会话 |
| ChatGPT | 投放账号导出 ZIP/JSON；当前环境可提供会话工具时使用真实快照 | 新导出或工具可发现的新消息 |
| 微信 | 先导入已授权导出；支持现有读取工具的环境再引导安装、登录和历史迁移 | 按会话增量获取，保留本人归属 |
| 健康 | 填写基本信息、导入自述或选定文件 | 按用户实际设备格式增加适配器 |
| 消费 | 投放微信支付或支付宝账单；XLSX 按独立解析模块适配 | 新账单；Gmail 附件连接为可选项 |
| 日记与其他资料 | 选择文件，保留日期和全文 | 手工投放新文件或启用选定目录 |

## 改变选择

用户可以追加来源、扩大或收窄时间范围、修改略过会话、改变哪些资料允许 dot 使用。配置变化决定后续采集、阅读队列和导出范围。

停止采集、停止 Agent 使用和删除已保存资料是不同操作，界面让用户选择对应动作。停止 Agent 使用时，处理相关阅读副本、云端可用副本和由它们形成的 Wiki 条目；原件是否保留按本人的选择执行。

## 当前命令

```text
personal-agent init       创建工作区与首轮配置
personal-agent sources    启用或修改来源范围
personal-agent collect    收取已启用来源
personal-agent digest     提供阅读队列并衔接当前 Agent
personal-agent export     生成允许提供给 dot 的脱敏包
personal-agent dot        生成或执行当前环境支持的 dot 接入步骤
personal-agent sync       处理本地与云端已授权更新
personal-agent status     查看接入 阅读 交付与待操作项
```

当前命令已实现。sources --discover 提供标题和 ID，dot 可让用户按标题选择后保存范围；status 显示接入、阅读、交付与下一步。语义处理和平台日程保存分别以实际执行回执判断。
