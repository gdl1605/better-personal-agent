# 凭据筛除与上下文同步

更新时间：2026-10-13。主职责：处理秘密值，保留理解所需信息，并记录真实交付与合并结果。

2026-10-12，用户将首轮基础密钥与密码筛选明确聚焦微信记录；Codex 与 ChatGPT 记录暂不处理。已实现的工具与操作见 [微信基础脱敏](wechat-redaction.md)。未来来源是否启用筛除由配置决定，当前示例只选择微信。

启用筛除的来源在交给 Agent 阅读之前处理：如果原文先进入模型上下文，事后仅在上传包中删除秘密值无法撤回此前暴露。

## 原件和阅读副本

原件保存在本地用户工作区，保留完整资料与出处；读取器生成脱敏副本供 Agent 阅读、分类和建立 Wiki。导出只从用户允许的阅读副本与 Wiki 取内容。源文件不被脱敏操作改写。

原个人库直接渲染来源视图；当前微信适配器先处理凭据，再生成月份视图与完整字段副本。未知微信格式也先处理适配样本；所选日期尚未能解释时只提供结构供 Agent 适配。

这里区分 Harness 的文件操作入口与 dot 的电脑权限。Harness 可以限定自己提供的目录；dot 获得的电脑访问权限由平台管理。文档和路径约定不能宣称已构成操作系统层面的原件隔离。

## 两类处理

| 类型 | 首版处理 |
| --- | --- |
| 密码、API key、私钥、授权 Cookie、访问令牌及带访问权的 URL 值 | 本地规则识别有明确凭据含义的字段或格式，替换秘密值，保留周边语义 |
| 姓名、联系方式、位置、商户、健康和关系内容 | 本版保留语义，通过来源与页面提供范围选择使用；细粒度别名化为后续扩展 |

个人上下文需要实际语义。关系称谓、目标、约束、时间和支出金额不因为“个人信息”就统一删除。别名化在用户选择时保持跨记录一致，映射留在本地，不随包上传。

## 识别与替换

优先处理明确的结构字段、私钥块、带认证含义的授权头、账号密码连接串和已识别的令牌格式。JSON 内嵌 XML、转义 JSON 或 URL 时，在对应容器中定位秘密值；替换后仍保留可解析的文本结构。

单独出现 token、key、密码等词不证明存在秘密值。无法定性的候选记录位置和含义，Agent 或用户据上下文判断；候选值不写入普通日志。不能凭字符串长度或熵值直接隔离整个来源。

已确认存在未处理凭据时，处理该字段或将该内容保持本地；同批其他已处理内容继续导出。批量结果分别说明已处理、仅留本地和需要用户选择的范围。

处理记录保存规则类型、源位置、替换数量和结果，不保存秘密值或秘密值片段。自动筛除提供具体规则覆盖，不能承诺任意格式的所有凭据都已识别。

## 导出包

包内保留读取规则、薄地图、用户允许的 Wiki、选定来源副本和一个交付清单。清单记录包版本、范围、生成时间、文件位置、来源修订与需要合并的变更；具体文件按用户范围选择，不要求每轮全库打包。

本地绝对路径改成包内相对路径，保留消息节点、交易行或来源锚点。云端引用可访问的脱敏副本，同时保留原件身份作为回查说明，不能把 Mac 路径伪装成云端可读取文件。

`.env`、凭据存储、浏览器登录资料和数据库解密密钥不进入上下文包。二进制附件按用户选择与已有处理能力提供；聊天数据库先转换成可读副本。压缩不能替代凭据处理。

## 上传与应用

打包、上传、云端取得文件、解包、Wiki 合并和 dot 读取是不同阶段。传输模块按真实返回记录远端引用；云端处理模块记录实际应用的文件、待处理项和当前主落点。

批量中某项失败保留其实际状态与原因，已成功结果继续保留。网络等待或工具超时后查询真实状态，避免把本地超时直接当成远端未接收。重跑先看已有回执和远端情况，再处理未交付部分。

清单和版本用于续接与比较。哈希如由传输协议要求则遵守该协议；其余校验只是定位变化的工具，不定义新的完成标准。

## 本地和云端合并

保留上次已同步的共同基线。只有一侧变化时同步该变化；两侧都变化时保留双方修改，根据原文、日期、表达者和用户决定合并。文件修改时间不能独自决定哪份个人认识正确。

同一事实仍更新同一主落点，地图只在路由变化时调整。用户明确的新决定替换对应旧决定，其他来源的不同观点保留归属。删除按用户请求的范围处理，不根据某端文件暂时缺失自动删除另一端资料。

源选择、云端可读范围改变后，后续包按新范围生成，已有 dot 发布入口自动刷新。停止后续采集保留已有理解；明确停止使用通过 withdraw 处理，原件是否删除按本人选择执行。

## 资料撤回与范围收窄

收窄日期、会话或文件范围时，清理旧阅读副本和依赖它的 Wiki 页，再按新范围接入。当前出处记录到页面，无法机械判断混合页面里每句的归属；受影响页回到空白模板，并把仍获准的来源交给 Agent 重建。其他页面和资料继续使用，不从撤回页提炼新认识。

明确停止使用某来源时，同时关闭采集、消化和发布，移除该来源阅读副本、旧阅读任务、回执和派生页。默认保留本工作区原件；明确删除时才移除 raw/inbox 中的该来源文件，外部原始输入文件不删除。初始自述和本人确认的原文也按这一选择处理。

来源使用范围的修订随任务和包保存，旧回执、旧云端来源与派生页不能重新合入当前库。仅收窄日常提供范围不要求重新阅读本地已理解资料。

工具移除可识别为本工作区所有的旧本地导出包，保存已登记远端引用及待执行操作。dot 使用实际原生工具处理旧包、解包副本与据此保存的相关笔记，再提交真实 removed/failed 回执；本地撤回不会冒充远端完成。未登记的手工副本需用户提供实际位置，不能声称已从所有位置抹除。具体命令与回执由 [commands.md](commands.md) 拥有。
