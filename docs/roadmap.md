# 当前实现与后续建设

更新时间：2026-10-13。主职责：区分已实现的基础设施、真实运行依赖与可按需求扩展的能力。

## 已实现的 0.1

| 用户路径 | 当前实现 |
| --- | --- |
| 开始配置 | 自然语言 Bootstrap、可选终端 setup、init 参数入口与独立工作区 |
| 首次实际使用 | onboard 续接认识展示、本人确认或纠正、依据当前 Wiki 处理真实问题 |
| 选择来源 | 六类来源分别启用；会话发现、时间范围、include/exclude、处理与提供范围 |
| 接入材料 | Codex 主会话、ChatGPT 导出/App 快照、微信快照/文本/本机工具、账单 CSV/ZIP/XLSX、健康与自述文件 |
| 处理凭据 | 复用微信初筛模块，先处理再生成可读副本；未知格式生成适配样本 |
| 建立理解 | Wiki 模板、待阅读任务、版本、部分阅读、主题索引与真实回执 |
| 校准认识 | 本人确认替换对应章节；Agent 可提交有出处的完整页面更新 |
| dot 日常入口 | 按提供范围生成发布副本；反馈、消化、采集和同步写入后刷新已有入口 |
| 资料撤回 | 清理阅读副本及派生页、按剩余来源重建、处理旧本地导出与登记的远端待办 |
| 持续运行 | maintain 串联；外部 Agent 命令协议；给 dot 的周期请求和真实任务引用登记 |
| 双向交换 | 工具与上下文一起打包；原生上传回执/命令适配；返回包按基线合并，双方修改保留 |

所有入口由 personal-agent 和 personal_agent 包提供，见[命令与协议](commands.md)。个人资料不进入源码仓库。

## 验证范围

v0.1.0 的 46 项测试覆盖来源选择、角色与分支、读取前凭据替换、CSV/XLSX 交易语义、来源行、自然语言启动、Wiki 回执与导航、发布范围、包内独立运行、双向合并、资料撤回和首次使用续接；同时覆盖 ChatGPT 导出与工具消息合并、Codex 缺少归档目录、微信截止日期、长聊天及文档分段续读、跨分段主题累积和深层 Wiki 原文链接。

外部 Agent 与上传命令的测试使用本地协议处理器，验证工具衔接，不证明 dot 的实际模型消化或云端上传。语义阅读、上传、应用与平台日程分别按真实执行记录判断。

## 运行环境需要完成的动作

用户选择数据后完成导出、微信登录或电脑连接。dot 实际读取生成的 instructions 并提交回执；原生文件工具执行交付，或配置当前环境的 uploader_command。周期任务由 dot 原生工具保存后登记真实引用。

这些步骤有实际操作入口和保存状态，未发生的动作不标为完成。未完成某一来源的设置，不阻止其他已选资料接入；未读历史不阻止已有 Wiki 发布。

## 后续按实际需求扩展

健康设备的专有格式和直接接口需要对应来源与样本；图片、音视频识别尚未接入。独立图形界面可复用现有配置与状态接口。其他 Agent 可直接承接同一读取/回执流程，或配置命令协议。

已有能力达到当前使用结果后停止扩大验证；格式或行为新增时复用相关测试，有独立新行为再补对应测试。
