# 周期接入与语义消化说明模板

由运行适配器填入当前可用命令、工作区与来源范围。不要把模板中不存在的能力当作已实现工具。

先读取 `{{AGENT_CONTEXT_ROOT}}/AGENTS.md`、薄地图和当前配置。只收取已启用来源与选定范围，按实际格式保留原件和出处；对已启用凭据筛除的来源先处理，再进入 Agent 可用副本，当前先覆盖微信。

调用当前运行环境提供的 `{{COLLECT_COMMAND}}` 和 `{{PENDING_COMMAND}}`。先读已理解材料的变化和新增来源，再继续未读历史。来源视图用于阅读，原件用于必要回查；只有获准提供的副本可以进入模型上下文。

阅读时识别本人事实、目标、约束、决定、协作要求、阶段投入和一般知识问题。更新实际有变化的 Wiki 主落点，保留日期与消息位置；普通工作资料可以只分类。本人表达与对方观点、引用和历史助手建议分别判断。

记录实际读到的来源版本、主题、理解页和处理结论。未读完时保留续读位置，新到达版本继续等待处理。完成后使用当前接口 `{{RECORD_COMMAND}}` 保存阅读回执，再执行已授权的 `{{EXPORT_OR_SYNC_COMMAND}}`。

有理解变化时简短报告改变了什么；只有接入变化时说明真实范围；出现具体获取错误或需要本人操作时说明对应步骤。没有新理解且没有需处理变化时保持安静。
