# 读取与文档维护

主职责：一份理解写在哪里、何时回写，以及如何记录实际阅读范围。

根 README 是薄地图，板块 README 是详细地图。理解页保留更新时间、范围、职责与来源指针。Wiki 保存个人结论，来源层保留材料，状态层记录工具结果。

核心信息由关于用户拥有；目标与选择由对应页拥有；协作要求由协作偏好拥有；生活主题按材料逐渐生长。一条事实只有一个主落点，其他页面用链接。

Agent 先读新增或已变化材料，再继续未读历史。阅读后维护主题和实际有变化的理解页，并记录读到的来源版本。部分读完时保存续读位置；来源更新后继续进入队列。

冲突先比较日期、表达者、对象与主张类型。本人明确的新决定更新对应旧决定，分析随新证据修正。重要经历与日记保留完整可用原文并连接摘要。

每轮只更新真正改变的理解和必要导航。没有语义变化不刷新全部页面。同步按本人选择执行，上传和阅读各自记录实际结果。
