# Personal Agent Harness

**由 dot 带你建立、使用和持续维护自己的个人知识库。**

你选择愿意提供的资料，dot 从中整理你的背景、目标、约束、经历和协作偏好，保存为可查看、可修改、有出处的个人 Wiki。之后讨论问题、安排事情或作出选择时，dot 读取相关认识；你有新的表达、决定或纠正，它就更新这份库。

用户通过自然语言完成这些事。创建工作区、接入资料、整理文件、保存阅读进度、更新认识和同步副本，都由 Agent 操作。

当前版本：0.1。更新时间：2026-10-13。本地工具使用 Python 3.9 及以上和标准库，无需额外安装 Python 依赖。

## 这个项目具体提供什么

Harness 是支撑个人 Agent 工作的一套工具、规则和流程。它把分散的资料变成可以持续使用的个人上下文，首个日常入口是 OpenAI 的 dot。

| 组成 | 里面有什么 | 对你的作用 |
| --- | --- | --- |
| 个人 Wiki | 当前背景、目标与选择、协作偏好、生活记录，以及逐渐形成的主题页 | 让 dot 依据你的实际情况回答问题，减少反复解释背景 |
| 来源与出处 | 你提供的聊天、自述、文件和账单；保留表达者、日期与来源位置 | 能回看一条认识从哪里来，也方便纠正误解 |
| 持续整理流程 | 新资料接入、增量阅读、长材料续读、理解更新和重要未知的校准 | 资料增加后继续整理，认识变化后及时更新 |
| dot 使用入口 | 当前允许提供的 Wiki 和阅读副本，以及读取、回写约定 | 日常交流能用到最新认识；选择云端副本后，电脑离线时也可继续使用已提供内容 |
| 用户控制 | 来源选择、使用范围、暂停采集、撤回资料和原件保留选择 | 由你决定哪些资料参与理解、哪些内容供 dot 使用 |

这里的“个人知识库”首先围绕你本人建立：你在做什么、看重什么、受哪些条件约束、经历过什么、希望 Agent 怎样配合你。项目资料、知识问答和他人的观点保留自己的归属，个人结论依据你的表达和实际记录形成。

资料保存为 Markdown、JSON 等本地文件。Wiki 是你可以直接查看、修改、备份和迁移的持久资料层；dot 是日常交流与执行入口。

## 怎样开始

在这个项目的 Codex 对话，或已经关联项目的 dot 中，直接说：

> 初始化

“执行初始化”“开始安装”“帮我配置个人 Agent”也会进入同一流程。已有工作区时会继续使用原来的资料与选择。

如果是第一次让一个新的 dot 使用项目，先把项目文件夹放到电脑上并告诉它位置，例如：

> 用 `/项目路径/personal agent` 带我建立个人知识库。我想让你先帮我安排学习和个人项目。

使用本机文件时，在 dot 的电脑设置里完成一次电脑访问授权。此后 dot 可以通过已连接电脑操作项目；使用本机期间保持电脑在线、ChatGPT App 打开。dot 自己的云端电脑可以在你的设备离线时继续工作。[OpenAI 官方电脑连接说明](https://learn.chatgpt.com/docs/dots/computers-and-apps)

个人库初次默认放在 `~/PersonalContext`，也可以在对话中指定其他位置。项目会记住已选工作区，下次继续使用。**只提供一段自述或一个当前目标就可以起步，其他资料以后逐渐增加。**

### 第一次使用会发生什么

1. **了解你当前想解决的事。** dot 复用已有回答，补充了解目标、重要约束和愿意提供的资料。
2. **保存你的选择。** 确定接入哪些来源、什么时间或会话范围、哪些材料用于整理认识，以及日常 dot 可以使用哪些内容。
3. **收取并阅读首批资料。** 已有文件由 dot 处理；需要你导出、登录或授权时，它说明具体操作。其他已提供的资料可以先继续。
4. **展示对你的认识。** dot 简短说明已经理解的背景、目标、约束和重要待确认项，你可以直接确认或纠正。
5. **实际解决一个问题。** dot 写回纠正，读取更新后的 Wiki，接着回答你当前的问题或完成一项具体工作。
6. **进入日常使用。** 以后直接交流、补充资料或改变安排；持续整理、云端同步和校准按你的选择运行。

初始化期间，Agent 会默认配置两项自动维护：按你的时区每天 21:00 同步与续读、每周日 10:00 校准理解。你可以调整或关闭，已有选择会保留。它会使用真实平台工具保存任务，并说明实际保存结果；未选择的资料仍不接入。

例如，你希望安排本周的课程和项目。dot 整理资料后认为你每周能投入十小时，你纠正“这周只有五小时”。它会更新这个约束，再给出符合五小时条件的安排。

首次引导会分别记录配置、认识展示、本人确认和实际回答。中途离开后可以续接；明确的纠正本身可以作为确认，无需再确认一遍。详见[完整引导流程](docs/onboarding.md)。

## 哪些操作由 dot 完成，哪些需要你来做

| 事情 | dot / Agent 负责 | 你需要做什么 |
| --- | --- | --- |
| 创建或恢复个人库 | 检查可用环境，创建目录，保存选择，记住入口 | 首次提供项目位置；需要改位置时直接说 |
| 明确目标与资料范围 | 用简短问题了解需求，把回答转成配置 | 表达目标，选择愿意提供的来源和范围 |
| 连接电脑与账号 | 说明缺少哪项连接，并接着完成工具操作 | 在平台界面完成登录、扫码、验证码或权限授权 |
| 导入已有资料 | 读取已选文件或当前工具能访问的记录，处理格式和出处 | 指定文件；来源要求本人导出时完成导出 |
| 整理与维护认识 | 阅读资料、分类、更新 Wiki、保存进度、刷新日常入口 | 查看重要认识，直接纠正不准确的内容 |
| 回答当前问题 | 读取相关认识，给出适合当前目标和约束的结果 | 提出问题，反馈实际情况与结果 |
| 持续整理和同步 | 按选择保存平台任务，补取新材料，更新并交付获准副本 | 选择或调整安排；平台需要重新授权时配合 |
| 暂停、撤回或删除 | 执行对应操作，处理相关认识与副本，说明实际结果 | 说明希望暂停什么、停止使用什么，以及原件是否保留 |

**你不需要记住命令、编辑配置文件、整理会话 ID 或填写 JSON 回执。** 这些是 Agent 的内部操作接口。账号登录、资料授权和对个人认识的确认由你完成。

## 可以提供哪些资料

所有外部来源分别选择。你可以只用其中一种，也可以逐渐组合使用。

| 来源 | 当前怎样接入 | 需要本人参与的部分 |
| --- | --- | --- |
| 自述、目标、日记 | 在对话中表达，或提供 Markdown、TXT、JSON、CSV 文件 | 说清重要背景和当前需求，或选择文件 |
| Codex | 读取本机已选主会话日志，按日期和会话范围接入 | 选择范围；已有本机记录通常无需另外导出 |
| ChatGPT | 使用当前环境可读取的会话工具结果，或导入账号导出的 ZIP / JSON | 选择会话；工具无法取得所需内容时，按需完成账号导出 |
| 微信 | 导入选定文字、快照；支持的 macOS 环境可使用本机微信读取工具 | 提供导出，或完成读取工具的安装、本人登录和所需历史迁移 |
| 健康 | 自述、文字或带日期的 JSON / CSV 记录 | 选择愿意提供的信息或设备导出文件 |
| 消费 | 微信支付、支付宝等账单 CSV / ZIP，以及已适配的微信支付 XLSX | 在来源应用申请账单并提供文件；加密账单按提示完成解密 |

读取时保留本人、助手、朋友或群友的归属。账单记录金额、收支和交易状态；消费动机、预算与生活偏好结合本人表达理解。重要经历保留可回查的原文。

ChatGPT 工具能取得的范围由当前环境决定，dot 会继续可用的历史分页或请你提供导出。健康设备的专有格式、其他新格式按实际样本适配；当前内置接入以文字和结构化记录为主，图片、音视频识别不在本版内置流程中。

## 哪些是可选项

| 选项 | 可以怎样选择 |
| --- | --- |
| 外部资料来源 | Codex、ChatGPT、微信、健康、消费分别启用，也可以全部先不接 |
| 读取范围 | 选择日期、会话、文件或目录，排除不希望使用的部分 |
| 是否参与理解 | 交给 Agent 阅读并形成认识，或只在本地归档 |
| 日常 dot 使用范围 | 只提供整理出的 Wiki；提供 Wiki 与选定原文副本；暂不提供该来源 |
| 云端资料副本 | 在 OpenAI dot 云端保留获准内容，或使用连接电脑的本地入口 |
| 持续整理 | 使用默认安排、调整时间，或关闭周期任务、按需补充 |
| 理解校准 | 按选择定期梳理变化与重要未知，或在日常对话中自然校准 |
| 原件保留 | 撤回使用后保留本地原件，或删除个人库中保存的对应原件 |

当前[配置模板](config/example.json)给出每日 21:00 整理、每周日 10:00 校准的安排，并包含云端同步选择；时间按个人库时区解释，可以在对话中调整或关闭。dot 会把配置落实为平台实际任务，并说明保存结果。平时只在理解有变化、出现具体问题或需要你操作时通知。

“让 Agent 阅读资料以形成认识”和“日常 dot 保留哪些内容”是两个选择。例如，你可以让 Agent 阅读一份聊天，只把整理出的目标和约束提供给日常入口。阅读阶段会使用 OpenAI 模型，云端副本则按你选择的范围保留。

## 日常怎么用

| 你可以这样说 | dot 会怎样处理 |
| --- | --- |
| “结合我的情况，帮我安排这一周。” | 读取当前目标、可用时间和约束，给出安排 |
| “这个项目已经结束了，更新一下。” | 更新对应认识，让后续回答使用新的阶段状态 |
| “刚才那个判断不准确，我的意思是……” | 保留你的明确纠正，修改原来的理解主落点 |
| “把这份新日记也整理进去。” | 接入新材料，继续更新相关主题与认识 |
| “你现在对我的目标是怎么理解的？” | 展示当前认识及其依据，供你核对 |
| “以后只看最近三个月的这部分资料。” | 更新范围，撤下旧范围对应的认识，再根据仍获准资料整理 |
| “先暂停继续收取微信。” | 停止新增采集，保留已有资料与认识 |
| “以后不要再用微信资料理解我。” | 撤回该来源的阅读副本和派生认识，处理相关交付副本 |
| “整理改到晚上九点半，没变化就不用通知。” | 调整对应平台任务和通知条件 |

反馈、消化和同步写入后，已有 dot 日常入口会更新。你可以先使用已经整理好的认识，历史资料按进度继续读取。

## 数据放在哪里，怎样保护

### 本地知识库 + 你自己的 OpenAI 服务

**标准使用路径中的个人资料由你的电脑和你授权的 OpenAI 服务处理。项目本身不设置收集个人资料的后台，也不把知识库传给项目作者。** 原应用里的历史资料继续由原应用保存；本项目生成的个人库和获准云端副本分别放在你的本地工作区与 OpenAI dot 环境中。

| 内容 | 保存或处理的位置 | 用途 |
| --- | --- | --- |
| 本地原件 | 你的个人工作区 | 保存原始资料，供本人回查与管理 |
| 阅读副本、来源索引和 Wiki | 你的个人工作区 | 支持阅读、形成认识和日常更新 |
| Agent 实际阅读的内容 | OpenAI 模型服务 | 理解资料、生成和修正个人认识、回答问题 |
| 获准提供的云端副本与持续笔记 | 你自己的 OpenAI dot 云端环境 | 让 dot 持续使用已提供的知识，支持电脑离线时的交流与工作 |

使用 OpenAI 模型理解资料，本就需要把被读取的内容交给 OpenAI 处理。**采用 dot 云端，是在同一个 OpenAI 服务体系里延续这项服务，没有再增加一个由本项目运营的数据保管方。** 云端保存的是供持续使用的副本，范围由你选择；你也可以选择让日常 dot 只保留整理出的认识。dot 的云端电脑可以保留工作状态、文件和会话。[OpenAI 官方云端电脑说明](https://learn.chatgpt.com/docs/dots/computers-and-apps#use-the-cloud-computer)

本地文件由你的电脑账户、文件权限和磁盘保护管理；OpenAI 侧的数据使用通过你自己的 ChatGPT 数据控制设置管理。[OpenAI 官方数据设置说明](https://learn.chatgpt.com/docs/dots/controls#manage-data-settings)

### 项目具体做了哪些保护

- **按你的选择收取与提供。** 外部来源分别启用，日期、会话、文件和日常提供范围分别保存；未选来源不采集。
- **原件与阅读副本分开。** 原件保留在本地，日常入口和导出包从获准的阅读副本与 Wiki 生成，不直接打包原件目录。
- **先处理凭据，再交给模型。** 当前基础筛除覆盖微信中的明确密码、密钥、访问令牌等内容，保留理解所需语义。Codex、ChatGPT 等其他来源当前按选定内容接入；姓名、关系、健康和消费信息由使用范围管理。
- **登录沿用你自己的账号。** 登录、扫码和授权通过平台提供的界面完成；常规使用不需要向项目作者提交密码、Cookie 或 OpenAI API key。
- **认识可以纠正，资料可以撤回。** 收窄范围或停止使用时，撤下对应阅读副本与派生认识；旧回执和旧返回包不会把它们恢复回来。已登记的云端副本由 dot 使用实际文件工具处理，并保存结果。

本项目管理提供给 Agent 的文件与使用范围，电脑和账号权限由 OpenAI 平台及操作系统管理。删除云端内容时，dot 按其实际保存位置处理文件、副本和相关笔记；对话、Library 文件与记忆分别管理。[OpenAI 官方保存与删除说明](https://learn.chatgpt.com/docs/enterprise/chatgpt-work-cloud-security#data-handling-and-retention)

上述数据路径针对使用 OpenAI dot 的标准方案。额外连接第三方应用，或自行配置其他模型、上传器和存储服务时，数据去向随你选择的服务变化。具体处理方式见[凭据筛除与上下文同步](docs/privacy-and-sync.md)。

## 本地会得到哪些文件

项目代码与个人资料分开放置。项目目录保存通用工具、规则、模板和虚构示例；每个人有自己独立的个人工作区：

```text
PersonalContext/
  config.json          你的来源选择、使用范围和时区
  inbox/               待接入的资料
  raw/                 本地保留的原件
  agent-context/
    wiki/              可以查看和修订的个人认识
    sources/           来源视图与阅读副本
    state/             阅读进度
  dot-context/         供 dot 日常读取的当前发布副本
  exports/             按提供范围生成的资料包
  state/               引导、同步和交付等运行记录
```

你可以直接查看 Wiki，或在聊天里让 dot 展示某个主题。通常由 Agent 维护来源索引和运行记录。撤回时，混合来源的受影响页面会根据仍获准的资料重建，其他页面继续使用。

## 当前能力与扩展

当前具备自然语言启动、来源选择、资料导入、微信凭据处理、增量与分段阅读、Wiki 维护、首次认识确认、实际问题使用、日常入口刷新、资料撤回、上下文打包和返回合并。

语义理解由 dot 或当前 Agent 完成；本地工具负责组织材料与保存状态。ChatGPT 历史读取、云端上传和周期任务使用当前环境实际提供的工具。遇到需要导出、登录或连接的步骤，dot 会说明本人要完成的操作，并继续处理已有材料。

本机文件导入可跨平台使用，微信实时读取首先适配 macOS 的现有读取工具。新的来源格式和其他 Agent 可沿用同一套上下文与回写流程扩展。
